# Study Quest Shared Decks

This directory contains curated, shareable Study Quest decks in the `StudyCards` JSON format.

## Publishing a deck

1. Create and validate a deck in Study Quest.
2. Use **Export Shareable Deck** rather than **Export Deck**.
3. Review the JSON before publishing it.
4. Add the `.studyquest.json` file to this directory with a descriptive filename.

### Naming

Use lowercase, descriptive filenames with hyphens, for example:

`california-indian-tribes-chapter-2.studyquest.json`

### Privacy

Do not publish student names, school names, teacher names, personal notes, study history, quiz history, or other identifying/private information. Shareable exports intentionally omit local progress, session history, and validation notes.

The shared-deck library is intended to contain curated educational content that is appropriate to distribute publicly.
